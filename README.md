# У Близнецов — сайт ресторанного комплекса

Автономный статический прототип сайта для ресторана «У Близнецов» в Краснодаре. В проекте нет сборщика и внешних зависимостей: `index.html`, `styles.css`, `script.js` и локальные изображения можно разместить на любом статическом хостинге.

## Что сделано

- Первый экран с двумя понятными сценариями: обычный визит и банкет.
- Мобильная нижняя панель: звонок, бронь, WhatsApp.
- Интерактивный выбор банкетного зала.
- Форма заявки формирует персональное сообщение и открывает WhatsApp; для полноценного продакшн-приёма лидов можно подключить CRM или backend.
- Блоки для кухни, отзывов, маршрутов и контактов.
- Ссылки на 2ГИС, Яндекс Карты, Google Maps и WhatsApp.
- GitHub Actions для публикации через GitHub Pages.

## Важная проверка перед передачей ресторану

Открытые карточки расходятся по режиму работы, адресу корпуса, вместимости и среднему чеку. Перед запуском нужно подтвердить у администратора: номер телефона, часы, цены, актуальный список залов, банкетное меню, условия по алкоголю/пробковому сбору и разрешение на использование фотографий. Демонстрационные фотографии в `assets/` взяты из открытых карточек Restoranka, Restoclub и 2ГИС; для коммерческого запуска их следует заменить на материалы, согласованные владельцем.

Рейтинг и количество оценок в демонстрации отражают карточку 2ГИС на момент последней сверки и могут изменяться со временем.
